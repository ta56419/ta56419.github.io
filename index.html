Projects

DocuAgent — grounded document assistant

view on github →

Python, SQLite FTS5/BM25, RAG, LLM tool calling, GitHub Actions

A document assistant that retrieves Markdown evidence, passes relevant passages to an OpenAI-compatible model, and returns cited answers. Includes bounded tool use, a restricted calculator, offline tests, and a small retrieval benchmark.

Measured on the included synthetic corpus: 19/19 expected sections retrieved in the top 3; this is a small retrieval benchmark, not a factuality guarantee.

LLM Eval & Security Lab

view on github →

Python, RAG evaluation, citation checks, prompt injection, CI

An offline evaluation harness for saved LLM answers. Checks citations against supplied sources, expected refusals, and basic prompt-injection resistance, then exports a JSON report for CI. Its lexical grounding check is explicitly a heuristic, not a semantic fact checker.

Customer Churn ML Platform

view on github →

Python, pandas, scikit-learn, FastAPI, reproducible evaluation

A complete tabular ML workflow: schema validation, preprocessing pipeline, stratified holdout evaluation, model persistence, and a FastAPI prediction endpoint. On its 200-row synthetic holdout, the sample model reached ROC-AUC 0.744 and recall 0.819; these are demonstration results on generated data, not real customer outcomes.
